 # Telegram Bot Started
Методы для сообщений:

    message.from_user.id - узнать уникальный ID пользователя
    message.from_user.username - узнать юзернейм пользователя (начинается с "@")
    message.from_user.first_name - узнать имя пользователя
    message.from_user.last_name - узнать фамилию пользователя (при указании её в Telegram)
    message.text - позволяет узнать текст сообщения
    message.message_id - позволяет узнать ID сообщения
    message.content_type - позволяет узнать тип отправленного сообщения (текст, фото, документ и проч.)
    message.caption - позволяет получить подпись к медиа сообщениям (фотографии, видео и проч.)
    message.html_text - получение текста с исходным форматированием

Методы для нажатий:

    call.data - данные нажатой кнопки
    call.message - сообщение, к которому прикреплена кнопка
    call.from_user.id - уникальный ID пользователя
    прочие методы получения информации о пользователе, аналогичные сообщениям
